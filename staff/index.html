The 4 links

First-time setup, in order

  1. Open Admin, enter your admin key.
  2. Restaurants, then Add. Fill name, area and FSSAI. Save.
  3. Create a login for that kitchen. Send the ID and password to the owner.
  4. Menu: add each dish with its price. Switch the kitchen Open.
  5. Settings: set delivery fee, free-delivery amount, and the rider cost.
  6. Settings: create the dispatch login. Give it to your dispatcher.
  7. Settings: create a rider login for each rider. Give them the Rider app link.
  8. Open the customer page. The kitchen shows up by itself, in the same layout.

Every day

  1. Kitchen owner: open Kitchen link, log in, keep the screen on.
  2. Dispatcher: open Dispatch link, assign a rider when an order is ready.
  3. You: open Admin, Live tab, watch late orders. Press Pause if a problem starts.
